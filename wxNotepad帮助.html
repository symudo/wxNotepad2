欢迎使用 wxNotepad

wxNotepad 是一款小巧的桌面笔记软件。采用 SQLite3 数据库保存用户笔记，并支持笔记内容自动保存。使用GNU GPLv3协议。

开始使用

本软件为单文件绿色软件，解压至任意文件夹下即可使用。

数据文件位置

  • 默认情况： 程序在当前用户的 Roaming 目录下保存配置和数据文件。
  • 便携模式： 如需将数据保存在程序所在目录，请在当前目录下创建一个内容为空的wxNotePad.ini 文件。也可以将 Roaming/wxNotepad 下的所有文件复制到当前目录，然后运行程序。
  • 指定数据文件模式： 通过命令行开关-o选择程序使用的数据文件，或者通过命令开关-d path/to/your/wxNotePad.db来指定程序使用的数据文件。

界面布局

界面分为左右两部分：左侧为导航区，右侧为内容区。

  • 导航区： 使用树形控件组织文件夹和笔记层级。
  • 内容区：
    • 在选择文件夹时，显示内部内容预览。
    • 在选择笔记时，显示编辑器。

快捷键

  • 使用快捷键 F3 聚焦到导航区。
  • 使用快捷键 F4 聚焦到编辑器。

导航区功能（树形控件）

  1. 全部： 储存所有文件夹和笔记的主区域。
  2. 回收站：
    • 删除的笔记和文件夹将转移至此。
    • 支持在回收站与全部节点之间拖动节点来移动文件。
    • 回收站中的笔记不包含在“最近的笔记”页和“标签”中。
  3. 标签：
    • 可以创建任意数量的标签，并为笔记添加标签。
    • 一个笔记可以附带任意数量的标签。
    • 删除标签不会影响已添加该标签的笔记。
  4. 最近的笔记： 显示最近创建、修改或访问的笔记列表。
  5. 快捷操作： 可以使用快捷键Ctrl+Up/Down来交换当前节点与兄弟节点的位置。

笔记部分（编辑器）

  • 自动保存： 切换节点时，笔记内容将会被自动保存。
  • 分隔符： 在新行输入连续的四个 * 或 # 或 = 或 - 时，会自动替换为分隔符。
  • 计算器： 在新行输入 = 并按下回车时，会自动计算捕获到的算式。
  • 设置标题： 选中文字后，按下 F10，可快速设置为当前笔记标题。
  • 自定义链接/命令： 可以选中文字，右击打开自定义链接或命令（如打开自定义搜索引擎或运行自定义命令）。
  • 拖放支持：拖动文本或文件到编辑器中，将插入文本或文件路径。
  • 便携模式下拖放：在便携模式下（使用-d或-o命令行开关启动），拖动文件到编辑器中，将插入文件路径相对路径，同时文件被保存到所在数据库同目录。
  • 链接点击：Ctrl+单击打开识别的链接，支持便携模式相对文件路径。
  • 图片预览：Ctrl+悬停图片路径，将显示图片预览。支持jpg/jpeg/bmp/png格式的图片。
  • 大纲功能：被设置为“标题”“大纲级别一”“大纲级别二”样式的文本将作为导航显示在工具栏右侧的目录导航中。

菜单栏

  • 文件 - 导入和导出功能： 可以导入或导出节点，导入导出时保留文件夹/节点层级关系。导出时如果节点的名称重复或者包含路径不允许的字符，程序将自动处理。
  • 编辑 - 还原初始内容： 将会（在自动保存前）还原对当前笔记所有更改，恢复到笔记的初始状态。
  • 编辑 - 监听剪贴板： 开启时，剪贴板内容将会被自动附加到当前笔记的末尾。您可以在配置文件中设置来源窗口的黑名单。
  • 编辑 - 查找所有： 可以在全部笔记内容中查找输入的字符串，包括回收站中的内容。
  • 编辑 - 编辑标签： 可以查看和批量编辑当前笔记的标签。
  • 编辑 - 样式： 为选中文字清除或设置样式。其中“标题”“大纲级别一”“大纲级别二”样式将作为目录导航生效。
  • 导航 - 上一视图： 返回至上一视图。可以重复使用 Alt + Left 快捷键在两个视图间来回切换。
  • 导航 - 快速切换功能：
    • 可以为“全部”下的笔记节点分配一个热键。
    • 使用 Alt + 数字 (1-0) 快速切换至该节点。
    • 节点被移动至回收站后，该快捷键仍有效，直至节点被永久删除。
  • 设置 - 高亮选中匹配： 如果在选择文字时出现卡顿，可以尝试关闭该功能。
